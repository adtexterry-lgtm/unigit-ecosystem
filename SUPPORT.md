# Support

- Product information and current availability: [unigit.ai](https://unigit.ai/)
- Get UNIGIT: [unigit.ai/download](https://unigit.ai/download/)
- Recommend a public resource: use this repository’s Resource Issue form
- Ecosystem and commercial partnerships: use the Partnership Issue form
- Security issues: read [SECURITY.md](./SECURITY.md)

This repository does not handle account, billing, customer-file, or production-environment support. UNIGIT will never ask you to post that information in a public Issue.
